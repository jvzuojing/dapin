## 地图配色美化（src/components/FillRateMap.vue）

- 现象：盟市/旗县区下钻后整片死蓝 `#0c3c6d`。根因不是配色审美，而是**数据缺失降级**：`regions` 只给有指标的面着色，旗县区级覆盖率接口尚无数据 → `items=[]` → `regions=[]`，所有面回落到 `geo3D.itemStyle.color` 默认色，且高度全为默认 1.8，看不出立体厚度。全区视图有 12 盟市数据所以是青蓝渐变。
- 改法：
  - 新增多段色阶 `RATE_STOPS`（有指标）/ `OUTLINE_STOPS`（纯轮廓）+ `stopsColor()` 线性插值；`scatter()` 用黄金比例散列给无数据面一个稳定、可区分的同色系色（仅视觉区分，不表达数值高低）。
  - `regions` 改为覆盖当前地图**所有面**：region 用 `regionNames`，city/county 取 `resolved.features[].properties.name`；每个面都显式设 `height`，无数据时轻微起伏。
  - 归一化改为 `lo=min-6`、`hi=max+6`、`span>=24`，避免数据挤在窄区间时整图同色、两端贴死色阶。
  - 兜底底色 `#124a82`；边框 `rgba(168,238,255,.78)` 且更细；emphasis 亮青描边；label 字号/描边优化；主光 1.15 + 环境光 `#7ab4dd` 0.7（lambert 不再压成灰蓝）；bloom 0.22；容器加径向光晕伪元素，`canvas z-index:1`、`legend/tip z-index:2`。
  - 图例新增 `legendActive`（在 buildOption 按 `items.length` 赋值）：无数据时显示「行政区划轮廓 / 暂无指标数据」，色条走 `is-outline` 无发光样式，不再展示假的 `0% ~ 100%`。
- 想更沉稳：整体压低 `RATE_STOPS` / `OUTLINE_STOPS` 亮度即可，色阶常量集中在文件顶部。
- 验证：`npm run build` 通过；本地生产包 + 无头浏览器实测 region / city / county / click 四态。全区图例「村社覆盖率 62% ~ 93%」；盟市视图 9 个旗县区呈多档青蓝；点击后 path `150000 / 150100 / 150102`、返回按钮齐全、图例切轮廓模式、地图切单块聚焦。三级下钻链路未受影响。

## 排查结论：项目里没有「默认 regionCode」常量

- 链路：`useDashboardApi.ts:39` 是 `const regionCode = ref('')`；`App.vue::bootstrap()` 先 `initRegionTree()`（`getRegionTree()` 不传 code，按登录用户取区划树），成功才用根节点路径设 `selectedRegion`/`activeCode` 并 `loadAll(code)`；`useRegionData.ts:495` 的 `regionCode` 是 `selectedRegion` 末项的 computed，空则 `''`。区划树接口失败/302 时 bootstrap 在 catch 后直接 return，regionCode 保持空、不发数据请求、面板走 mock 降级、下拉框无默认选中。

## 修复：地图点击无法下钻 + 左上角联动
